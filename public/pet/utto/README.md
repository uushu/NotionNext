# utto 灵宠素材包 v1

建议放入 NotionNext 仓库：

```text
public/pet/utto/
```

首发状态：

- `idle.gif`：默认待机
- `reading.gif`：文章阅读
- `exploring.gif`：分类、标签、归档和搜索
- `bored.gif`：短时间无操作
- `break.gif`：休息喝饮料
- `sleep.gif`：长时间无操作或夜间睡眠
- `interact.gif`：单击互动和普通成功反馈
- `annoyed.gif`：连续点击或一般错误
- `success.gif`：读完文章、分享或复制成功
- `fatal-error.webp`：404 或严重错误
- `fatal-error.png`：WebP 回退版本

说明：

1. 九个 GIF 保留原始透明背景和动画节奏。
2. 严重错误静态图已抠除与边缘连通的白色背景，保留兔子身体内部白色区域。
3. `manifest.json` 包含状态含义、触发条件和优先级。
4. 图片仅建议用于你有权使用的个人博客。
